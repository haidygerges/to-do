## 🌟 Overview

A beautiful and responsive **To-Do List** web application built with vanilla HTML, CSS, and JavaScript — no frameworks needed. It features a stunning **Glassmorphism** design, smooth animations, dark/light mode, drag-and-drop reordering, and full local storage persistence.

---

## ✨ Features

- 🎨 **Glassmorphism Design** — frosted glass cards with blur effects and soft borders
- 🌙 **Dark / Light Mode** — toggle between themes with smooth transition
- ⭐ **Star Important Tasks** — mark and filter high-priority tasks
- 📅 **Due Dates** — set deadlines with overdue highlighting in red
- 🔍 **Live Search** — filter tasks in real time as you type
- 🗂️ **Smart Filters** — view All / Active / Completed / Important tasks
- 🖱️ **Drag & Drop** — reorder tasks intuitively using SortableJS
- ✏️ **Inline Editing** — double-click any task to edit it on the spot
- 💾 **Local Storage** — tasks persist across page refreshes automatically
- 📊 **Live Stats** — real-time counters for Total / Completed / Remaining
- 📱 **Fully Responsive** — works great on mobile, tablet, and desktop

## 🎮 How to Use

1. **Add a task** — type in the input field and press `Enter` or click ⬆️
2. **Set a due date** — optionally pick a date before adding
3. **Mark as done** — click 😡 to complete a task (turns ❤️)
4. **Star a task** — click ☆ to mark it as important (⭐)
5. **Edit a task** — double-click the task text to edit inline
6. **Reorder tasks** — drag and drop to rearrange
7. **Filter tasks** — use the filter buttons (All / Active / Completed / Important)
8. **Search** — type in the search bar to find tasks instantly
9. **Clear done** — click "Clear Done" to remove all completed tasks
10. **Toggle theme** — click 🌙 / ☀️ to switch between dark and light mode
